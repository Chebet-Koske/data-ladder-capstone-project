# Data

The dataset is not stored in this repository because of its size (about 212 MB, 1.1M rows).

**File:** fmcg_sales_3years_1M_rows.csv
**Source:** https://www.kaggle.com/datasets/robertocarlost/fmcg-multi-country-sales-dataset/data

To run the notebooks:
1. Download the file from the source above.
2. Place it in this `data/` folder.
3. Run the notebooks in order. The processed files (`data/processed/`) and
   the SQLite database are created automatically and are not tracked in Git.
